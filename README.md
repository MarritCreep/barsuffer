# BarSuffer

Неофициальный планировщик расписания для студентов Бар-Илана. Собираешь семестр, видишь накладки,
окна и нагрузку, получаешь «индекс страдания» и шуточный титул.

> Это черновик. Сайт не связан с университетом, ни на что не записывает и ничего никуда не
> отправляет. Запись на курсы — только в Инбаре.

## Запуск

Нужен Node.js 22+.

```
npm install
npm run dev
```

Открыть адрес, который напишет Vite (обычно http://localhost:5173).

## Тесты

```
npm test             # логика: накладки, индекс, выбор групп
npx playwright test  # сайт в браузере (Edge), десктоп и телефон
```

## Данные

Сейчас это ручной образец (`src/data/sample-2027.json`): реальные курсы из одного расписания плюс
придуманные группы с пометкой DEMO. Кредиты — заглушки. Полный каталог появится только из
разрешённого источника.

## Что умеет прототип

- поиск по названию, номеру и преподавателю;
- недельная сетка Вс–Пт 08:00–22:00, семестры A и B, годовые курсы;
- выбор групп «призраками» на сетке, привязанные упражнения;
- накладки на сетке и списком;
- нажатие на пустую клетку — список курсов, которые идут в это время;
- автоподбор: отмечаешь обязательные курсы, он ищет 5 наименее мучительных вариантов;
- отмена и повтор (Ctrl+Z / Ctrl+Y), временное скрытие курса, удаление крестиком прямо на сетке;
- академические часы, кредиты, индекс страдания с разбивкой;
- сохранение в браузере, тёмная и светлая темы, телефон.
