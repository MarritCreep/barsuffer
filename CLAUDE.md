# BarSuffer

Бесплатный **неофициальный** планировщик расписания для студентов Бар-Илана: собрать семестр,
увидеть накладки и окна, получить «индекс страдания». Статичный сайт, без сервера и аккаунтов.

## Жёсткие правила (из диздока — не нарушать)

- **Никакого обхода защиты.** courses.biu.ac.il закрыт Radware/hCaptcha — не скрейпить его, не
  использовать код или данные biu-courses-crawler. Другие проекты (BIU-Course-Planner, CheeseFork) —
  только ориентир по функциям; код не копировать.
- **Данные — только разрешённые:** ручной образец или официальная выгрузка/разрешение университета.
  Полный каталог не публиковать, пока нет разрешения.
- **Никаких паролей и Инбара:** сайт не просит и не хранит учётные данные, не записывает на курсы.
- **Никаких личных данных в репозитории.** Папка `_private/` в `.gitignore` — туда кладём исходники
  с именами (распечатки Инбара и т. п.). Никогда не коммитить её содержимое.
- **Бесплатно:** без платных API, серверов, рекламы, скрытой аналитики.
- **Честность:** всегда видны подпись «Unofficial», дата снимка данных, напоминание сверяться с
  Инбаром. Без логотипа и стиля университета. Придуманные данные помечаются `isDemo` и бейджем DEMO.

## Решения по прототипу (ноябрь 2026)

- **Языки: English (по умолчанию), Русский, עברית (RTL).** `src/i18n/`: `core.ts` (формы множественного
  числа через Intl.PluralRules, `{параметры}`), `I18n.tsx` (`useI18n()` → `t`, `day`, `type`, `term`, `date`,
  `num`; `translator(lang)` без React), словари по областям `areas/*.ts` (ru/he типизированы как
  `Dict<typeof en>` — пропуск ключа не соберётся; тест `i18n.test.ts` сверяет параметры). Выбор в шапке,
  хранится в `barsuffer:lang:v1`, `lang`/`dir` ставятся до отрисовки (index.html). **Названия курсов не
  переводятся** (решение автора). Английский текст = селекторы e2e, менять осознанно. CSS — логические
  свойства (inline-start/end); карта кампуса и SVG не зеркалятся.
- Тёмная тема по умолчанию. Кнопка темы в шапке открывает панель (`src/ui/ThemePicker.tsx`,
  `src/state/appearance.ts`): основа Dark/Light, свой акцентный цвет (пипетка, ползунки R/G/B, пресеты),
  «Shimmering colour» — медленный цветной туман на фоне (`.fog`, оттенки цвета ±35°, без анимации при
  prefers-reduced-motion). Предпросмотр сразу, сохранение только по «Apply», «Cancel» возвращает.
  Цвет текста на акцентных кнопках подбирается по яркости. Текстовый логотип.
- Под логотипом — горящая кнопка «SUFFER» (CSS-пламя), открывает `public/skeleton-burning.gif`
  (грузится только по нажатию; мем — по решению автора).
- Окна, которые должны покрывать весь экран, но открываются из шапки, рендерятся через portal в body:
  у шапки `backdrop-filter`, и `position: fixed` внутри неё считается от шапки.
- Карта кампуса приближается колесом (к курсору), щипком двумя пальцами, перетаскивается с инерцией
  (`src/ui/useZoomPan.ts`), есть кнопки + / − / сброс.
- Mobile-first: на телефоне вкладки Courses / Week, на десктопе две колонки.
- Выбор групп «как CheeseFork»: нажал на курс → его группы-«призраки» пунктиром на сетке → нажал на
  призрак, и группа выбрана. Повторное нажатие на выбранную снимает выбор.
- Сетка: Вс–Пт, 08:00–22:00, одна клетка = один академический час. Пара 10–12 = 2 ак. часа.
- Накладки разрешены и подсвечиваются. Стык (10–12 и 12–14) — не накладка.
- Типы занятий: lecture, exercise, lab, seminar, proseminar, workshop, guidance, other. По одной группе
  каждого типа, который есть у курса. `linkedTo` привязывает группу (например, תרגיל) к группе
  другого типа; выбор привязанной группы сам переключает «родителя».
- Годовые курсы (`term: "year"`): один выбор действует на оба семестра; встреча может иметь
  `semester` для одного семестра.
- **Индекс страдания** (`src/logic/misery.ts`): день в кампусе 8, начало до 09:00 — 6 за занятие,
  час окна — 3 (окно ≥ 1 часа, считаются полные часы, только внутри дня), пятница — 12 один раз,
  конец после 18:00 — 5 за занятие (было 19:00 в диздоке, изменено по решению автора), максимум 100. При накладке считается только самое «тяжёлое»
  занятие кластера, окна — по объединённому времени. 10 английских титулов.
- **Что влезет в окно** (`src/logic/slots.ts`): нажатие на клетку сетки (один час) показывает все
  группы текущего семестра с встречей в этом часе. Уже выбранные группы скрыты, накладки с
  расписанием помечаются, курсы из плана можно переключить на эту группу. Пусто — «No courses meet
  at this time.»
- **Автоподбор** (`src/logic/autopick.ts`): сначала студент обязательно отмечает курсы, которые нельзя
  не взять (`required` в плане; без хотя бы одного поиск недоступен). Из остальных берётся ровно
  «N из M». Перебор с отсечением (branch and bound), стоимость = накладки × 1000 + сырой индекс
  страдания, топ-5, предел 200 000 узлов. Не вошедшие необязательные курсы скрываются (`hidden`), а не
  удаляются. Работает по текущему семестру; группы годового курса действуют на оба семестра.
- **Скрытие курса** (`hidden`): курс остаётся в списке, но не на сетке и не в подсчётах.
- **Undo/redo** (`src/state/history.ts`): Ctrl/⌘+Z, Ctrl+Y / ⌘⇧Z и кнопки в шапке; история только в
  памяти вкладки, до 100 шагов; в полях ввода Ctrl+Z не перехватывается. Действие без изменений в
  историю не попадает — редьюсер возвращает тот же объект.
- **Крестик на блоке сетки** удаляет курс: по наведению, на сенсорных экранах — у выбранного курса.
- **Прогноз на «призраках»** (`src/logic/preview.ts`): «+8 / −3» — изменение стандартного индекса.
- **Свои веса индекса** — ползунки в автоподборе (`src/state/settings.ts`, localStorage). Главная цифра
  на экране всегда по стандартным весам, чтобы её можно было сравнивать с друзьями.
- **Дорога**: минуты в одну сторону (плитка в шапке статистики) → часы в пути за неделю = дни × 2 ×
  минуты; показывается и в вариантах автоподбора.
- **Личные блокировки** (`plan.blocks`, `src/logic/blocks.ts`): создаются из панели клетки сетки,
  оба семестра или один. Дают накладки (сетка, «что влезет», автоподбор = накладка), но не входят в
  индекс и часы. «Clear all» их не трогает.
- **Сегодня** (`src/logic/today.ts`, даты семестров в `src/data/calendar.ts` из официального календаря
  תשפ"ז): прошло / идёт / следующее, «No classes today», суббота, каникулы, праздники.
  На телефоне — отдельная вкладка, на десктопе — блок над списком курсов.
- **«Беги!» и карта кампуса — ЭКСПЕРИМЕНТ** (`src/logic/campus.ts`, `src/ui/CampusMap.tsx`):
  координаты зданий для рисования сняты на глаз со схемы кампуса; на сайте своя схема (точки и номера),
  без официальной картинки. **Расстояния — в метрах:** 25 зданий с реальными координатами из
  OpenStreetMap (`src/data/campusGeo.ts`, ODbL — подпись «© OpenStreetMap contributors» на карте и под
  сеткой обязательна), остальное (здания без OSM, ворота, кафе) — схема, пересчитанная аффинным
  преобразованием по опорным зданиям (ошибка ≈ 12 м). Допущения: коэффициент дорожек 1,3, 70 м/мин,
  15 минут перерыва между «стыкующимися» парами. Демо-курс 99003 в здании 902 показывает «Беги!»
  (105 → 902 ≈ 16 мин).
  Окно карты на десктопе перетаскивается за заголовок, тянется за правый нижний угол, разворачивается
  (⤢ / двойной клик); положение в localStorage. Маршрут дня — непрерывная линия со стрелками и минутами,
  по желанию от ворот (שער, `GATES`) и обратно, с общим временем ходьбы; карта приближается к маршруту.
- «Сегодня» на десктопе — над индексом в правой колонке (в левой его не видно при длинном списке).
  Там же прогресс семестра (неделя N из M, сколько пар осталось), шаги за день и предупреждение о дожде.
- **Wrapped** (`src/logic/wrapped.ts`, `src/ui/Wrapped.tsx`): сторис по Sem A / Sem B / Year. Недельное
  расписание × реальное число каждого дня недели в семестре (`weekdayCount`). До периода — прогноз,
  во время — доля пройденного, после — итоги. Последний слайд рисуется в canvas (1080×1920) и
  сохраняется/шарится как PNG. Год: средний индекс семестров, титул — от более тяжёлого.
- **Карта страданий недели**: `dayMisery` / `hellDay` — индекс каждого дня, цвет в заголовке сетки.
- **Кофе в окне** (`src/logic/coffee.ts`): окна ≥ 1 часа, ближайшее по пути кафе (точки сняты со схемы,
  ЭКСПЕРИМЕНТ), время туда и обратно, остаток на кофе.
- **Дождь** (`src/logic/weather.ts`): Open-Meteo без ключа, только координаты кампуса, кеш на час;
  предупреждение, если переход ≥ 3 минут попадает на час с вероятностью осадков ≥ 50% или ≥ 0,3 мм.
  В e2e прогноз подменяется (`page.route`), тесты не ходят в интернет.
- **Шагомер** (`src/logic/walking.ts`): метры по схеме, шаг 0,75 м, забавные мерки (`FUN_DISTANCES`:
  от футбольного поля до линии Кармана). Ворота входа — общая настройка (`settings.gate`).
- **Импорт из Инбара** (`src/logic/inbar.ts`, `src/ui/ImportDialog.tsx`, `src/ui/readPdf.ts`): студент сам
  экспортирует PDF «Schedule → All Semesters» и загружает его; pdf.js (грузится только при импорте) читает
  текст с координатами в браузере, файл никуда не уходит, строка «Logged in as …» отбрасывается. Колонки
  дней — по заголовкам «Sunday…», жирный шрифт — название «… (курс-группа)», дальше время или «Continued».
  Курсы и группы, которых нет в каталоге, **не создаются** — показываются как ошибка, остальное
  добавляется; группы с другим временем — предупреждение. Режим «добавить» или «заменить», один шаг undo.
  Тесты — на обезличенном снимке `src/logic/fixtures/inbar-schedule.json` (без имени); e2e с настоящим
  PDF берёт `_private/Schedule.pdf` и пропускается, если файла нет.
  Три вида распечаток Инбара: 1st Semester / 2nd Semester / All Semesters (`scope` по выпадающему списку
  и заголовкам; без подписи — студент выбирает семестр). «Заменить» убирает только курсы семестра из
  распечатки. **Перед изменением** — шаг проверки: что прочитано (группы, дни, время, аудитории) и что
  изменится (+ / ~ / −); кнопки «Apply changes» / «Don’t change».
- **Файл расписания** (`src/state/backup.ts`): «Save file» — JSON с планом и настройками, «Open file» —
  обратно (с проверкой; неизвестные курсы отбрасываются и перечисляются), тоже через подтверждение.
- После импорта и загрузки файла в уведомлении есть **Undo**: возвращает точную копию прежнего плана
  (и настроек), а не «последний шаг»; Ctrl+Z тоже работает.
- README на GitHub — на английском.
- **Праздники תשפ"ז** (`NO_CLASS_PERIODS` в `src/data/calendar.ts`, официальный календарь, зелёные дни):
  off / until (занятия до часа) / pause (церемония). Учитываются в «Сегодня», остатке пар, посещаемости,
  .ics. Сессии — `EXAM_PERIODS` (без деления на מועדים).
- **Инструменты** (`src/ui/ToolsBar.tsx`): на десктопе ряд кнопок над «Сегодня», на телефоне вкладка «Ещё».
  - **Календарь (.ics)** (`src/logic/ics.ts`, `sessions.ts`): каждая встреча — отдельное событие с реальной
    датой (праздники просто не попадают), TZID=Asia/Jerusalem + VTIMEZONE; по желанию блокировки,
    экзамены, праздники.
  - **Друзья** (`src/logic/share.ts`, `together.ts`): расписание целиком в ссылке `#friend=…` (base64url
    JSON), без сервера; в ссылке нет подписей блокировок и скрытых курсов. Сравнение: общие пары, общее
    свободное время 08–20 (☕ «оба в кампусе»), индексы, недели рядом; друзей можно сохранить
    (`barsuffer:friends:v1`). Хеш убирается из адреса после открытия.
  - **Посещаемость и милуим** (`src/logic/attendance.ts`, `AttendanceDialog.tsx`): правило по курсу — 80% по
    умолчанию / свой % / Оламот (макс. 2 пропуска за семестр) / нет; периоды милуим считаются пропусками.
  - **Экзамены** (`src/logic/exams.ts`, `ExamsDialog.tsx`): вводит студент; дни на подготовку, «индекс
    страдания сессии».
  - **Прогресс степени** (`src/logic/degree.ts`, `DegreeDialog.tsx`): 128 נ"ז (меняется), Оламот 20 с
    уменьшенными нормами и освобождениями (неевреи — 20 общих курсов), английский по баллу (פטור от 134,
    курсы EMI), הבעה עברית. Источники проверены 2026-11-06 — в шапке `degree.ts`.
- **Будильник** (`src/logic/wake.ts`): первая пара − дорога − 10 мин до аудитории − сборы; сон и сборы —
  настройки (`barsuffer:wake:v1`). **Хамсин** (`src/logic/heat.ts`): от 32° в часы в кампусе
  (temperature_2m из того же Open-Meteo).
- **Знакомство** (`src/ui/Tour.tsx`): при первом визите приветствие (пример расписания `src/logic/demo.ts` /
  тур / с нуля), 5 шагов с подсветкой; снова — «Инструменты → Знакомство». В автотестах
  (`navigator.webdriver`) само не открывается.
- Новые инструменты хранятся в localStorage (src/state/tools.ts) и пока не входят в «Save file».
- **Фильтры курсов** (`src/logic/filters.ts`, `src/ui/CourseFilters.tsx`) — почва под полный каталог.
  Поля как в официальном поиске Бар-Илана (кафедра, название/номер/преподаватель, день, время «от–до»,
  язык) и в карточке курса (факультет, тип занятия, кредиты, здание/комната, академические часы, экзамены,
  силлабус) + Оламот / General, семестр, онлайн (`Meeting.online`) и самостоятельное обучение (группа без
  расписания). Модель: `Course.departmentId / facultyId / categories / language / academicHours`,
  `Section.syllabusUrl`, `Catalog.faculties / departments`. Пустая группа — без ограничений, внутри — «или»,
  между — «и»; признаки группы (тип, место, день, время, слот) должны быть у одной группы сразу. Группа
  фильтра показывается, только если в данных есть значения (`buildFacets`, со счётчиками).
  Слева — кнопка «Filters», фильтр хранится в `barsuffer:filters:v1`. Клетка сетки: сначала фильтр (без
  семестра/дня/времени — их задаёт клетка; значения — только из групп этого часа), «Show N courses» /
  «Show all», потом список; фильтр клетки живёт в памяти вкладки. Сейчас поля заполнены только у DEMO-курсов.
- Отложено: карточка-картинка, варианты A/B/C.

## Стек и команды

React 19 + TypeScript 7 + Vite 8, Vitest 5, Playwright (через установленный Edge, `channel: msedge`).
Node ставился через winget; если `node` не найден в терминале — перезапустить VS Code.

```
npm run dev        # дев-сервер
npm test           # юнит-тесты логики (Vitest)
npx playwright test  # браузерные тесты (сами собирают и поднимают preview на :4173)
npm run build      # typecheck + сборка в dist/
```

## Публикация

Репозиторий публичный: github.com/MarritCreep/barsuffer. Сайт: https://marritcreep.github.io/barsuffer/.
`.github/workflows/deploy.yml` на каждый push в `main` гоняет `npm test` и сборку и публикует `dist/`
на GitHub Pages. Если тесты красные, сайт не обновится. Playwright в CI не запускается.

## Структура

- `src/data/types.ts` — модель каталога; `src/data/sample-2027.json` — образец (תשפ"ז).
- `src/logic/` — чистая логика без React: выбор групп, накладки, индекс, нагрузка. Всё с тестами.
- `src/state/storage.ts` — localStorage (план хранит только стабильные номера курсов и групп).
- `src/ui/` — компоненты и `styles.css` (токены тем на `:root[data-theme]`).
- `e2e/` — Playwright.

Любое изменение логики индекса или накладок — сначала тест. Контрольный пример в
`misery.test.ts` (реальное расписание: 30 в семестре A, 41 в семестре B) должен оставаться зелёным
или меняться осознанно.
