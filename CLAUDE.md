# BarSuffer

Бесплатный **неофициальный** планировщик расписания для студентов Бар-Илана: собрать семестр,
увидеть накладки и окна, получить «индекс страдания». Статичный сайт, без сервера и аккаунтов.

## Жёсткие правила (из диздока — не нарушать)

- **Никакого обхода защиты.** courses.biu.ac.il закрыт Radware/hCaptcha — не скрейпить его, не
  использовать код или данные biu-courses-crawler. Другие проекты (BIU-Course-Planner, CheeseFork) —
  только ориентир по функциям; код не копировать.
- **Данные — только разрешённые:** ручной образец или официальная выгрузка/разрешение университета.
  Полный каталог не публиковать, пока нет разрешения.
- **Никаких паролей и Инбара:** сайт не просит и не хранит учётные данные, не записывает на курсы.
- **Никаких личных данных в репозитории.** Папка `_private/` в `.gitignore` — туда кладём исходники
  с именами (распечатки Инбара и т. п.). Никогда не коммитить её содержимое.
- **Бесплатно:** без платных API, серверов, рекламы, скрытой аналитики.
- **Честность:** всегда видны подпись «Unofficial», дата снимка данных, напоминание сверяться с
  Инбаром. Без логотипа и стиля университета. Придуманные данные помечаются `isDemo` и бейджем DEMO.

## Решения по прототипу (ноябрь 2026)

- Интерфейс пока **только на английском**, LTR. Иврит/RTL и русский — позже.
- Тёмная тема по умолчанию, переключатель в шапке. Текстовый логотип.
- Mobile-first: на телефоне вкладки Courses / Week, на десктопе две колонки.
- Выбор групп «как CheeseFork»: нажал на курс → его группы-«призраки» пунктиром на сетке → нажал на
  призрак, и группа выбрана. Повторное нажатие на выбранную снимает выбор.
- Сетка: Вс–Пт, 08:00–22:00, одна клетка = один академический час. Пара 10–12 = 2 ак. часа.
- Накладки разрешены и подсвечиваются. Стык (10–12 и 12–14) — не накладка.
- Типы занятий: lecture, exercise, lab, seminar, proseminar, workshop, guidance, other. По одной группе
  каждого типа, который есть у курса. `linkedTo` привязывает группу (например, תרגיל) к группе
  другого типа; выбор привязанной группы сам переключает «родителя».
- Годовые курсы (`term: "year"`): один выбор действует на оба семестра; встреча может иметь
  `semester` для одного семестра.
- **Индекс страдания** (`src/logic/misery.ts`): день в кампусе 8, начало до 09:00 — 6 за занятие,
  час окна — 3 (окно ≥ 1 часа, считаются полные часы, только внутри дня), пятница — 12 один раз,
  конец после 18:00 — 5 за занятие (было 19:00 в диздоке, изменено по решению автора), максимум 100. При накладке считается только самое «тяжёлое»
  занятие кластера, окна — по объединённому времени. 10 английских титулов.
- **Что влезет в окно** (`src/logic/slots.ts`): нажатие на клетку сетки (один час) показывает все
  группы текущего семестра с встречей в этом часе. Уже выбранные группы скрыты, накладки с
  расписанием помечаются, курсы из плана можно переключить на эту группу. Пусто — «No courses meet
  at this time.»
- **Автоподбор** (`src/logic/autopick.ts`): сначала студент обязательно отмечает курсы, которые нельзя
  не взять (`required` в плане; без хотя бы одного поиск недоступен). Из остальных берётся ровно
  «N из M». Перебор с отсечением (branch and bound), стоимость = накладки × 1000 + сырой индекс
  страдания, топ-5, предел 200 000 узлов. Не вошедшие необязательные курсы скрываются (`hidden`), а не
  удаляются. Работает по текущему семестру; группы годового курса действуют на оба семестра.
- **Скрытие курса** (`hidden`): курс остаётся в списке, но не на сетке и не в подсчётах.
- **Undo/redo** (`src/state/history.ts`): Ctrl/⌘+Z, Ctrl+Y / ⌘⇧Z и кнопки в шапке; история только в
  памяти вкладки, до 100 шагов; в полях ввода Ctrl+Z не перехватывается. Действие без изменений в
  историю не попадает — редьюсер возвращает тот же объект.
- **Крестик на блоке сетки** удаляет курс: по наведению, на сенсорных экранах — у выбранного курса.
- **Прогноз на «призраках»** (`src/logic/preview.ts`): «+8 / −3» — изменение стандартного индекса.
- **Свои веса индекса** — ползунки в автоподборе (`src/state/settings.ts`, localStorage). Главная цифра
  на экране всегда по стандартным весам, чтобы её можно было сравнивать с друзьями.
- **Дорога**: минуты в одну сторону (плитка в шапке статистики) → часы в пути за неделю = дни × 2 ×
  минуты; показывается и в вариантах автоподбора.
- **Личные блокировки** (`plan.blocks`, `src/logic/blocks.ts`): создаются из панели клетки сетки,
  оба семестра или один. Дают накладки (сетка, «что влезет», автоподбор = накладка), но не входят в
  индекс и часы. «Clear all» их не трогает.
- **Сегодня** (`src/logic/today.ts`, даты семестров в `src/data/calendar.ts` из официального календаря
  תשפ"ז): прошло / идёт / следующее, «No classes today», суббота, каникулы. Праздники пока не учтены.
  На телефоне — отдельная вкладка, на десктопе — блок над списком курсов.
- **«Беги!» и карта кампуса — ЭКСПЕРИМЕНТ** (`src/logic/campus.ts`, `src/ui/CampusMap.tsx`):
  координаты зданий сняты на глаз со схемы кампуса; на сайте своя схема (точки и номера), без
  официальной картинки. Допущения: 1,2 м/пикс, коэффициент дорожек 1,35, 70 м/мин, 15 минут перерыва
  между «стыкующимися» парами. Демо-курс 99003 в здании 901 показывает предупреждение.
  Окно карты на десктопе перетаскивается за заголовок, тянется за правый нижний угол, разворачивается
  (⤢ / двойной клик); положение в localStorage. Маршрут дня — непрерывная линия со стрелками и минутами,
  по желанию от ворот (שער, `GATES`) и обратно, с общим временем ходьбы; карта приближается к маршруту.
- «Сегодня» на десктопе — над индексом в правой колонке (в левой его не видно при длинном списке).
- Отложено: карточка-картинка, ссылка другу и режим просмотра, варианты A/B/C, сравнение с друзьями.

## Стек и команды

React 19 + TypeScript 7 + Vite 8, Vitest 5, Playwright (через установленный Edge, `channel: msedge`).
Node ставился через winget; если `node` не найден в терминале — перезапустить VS Code.

```
npm run dev        # дев-сервер
npm test           # юнит-тесты логики (Vitest)
npx playwright test  # браузерные тесты (сами собирают и поднимают preview на :4173)
npm run build      # typecheck + сборка в dist/
```

## Публикация

Репозиторий публичный: github.com/MarritCreep/barsuffer. Сайт: https://marritcreep.github.io/barsuffer/.
`.github/workflows/deploy.yml` на каждый push в `main` гоняет `npm test` и сборку и публикует `dist/`
на GitHub Pages. Если тесты красные, сайт не обновится. Playwright в CI не запускается.

## Структура

- `src/data/types.ts` — модель каталога; `src/data/sample-2027.json` — образец (תשפ"ז).
- `src/logic/` — чистая логика без React: выбор групп, накладки, индекс, нагрузка. Всё с тестами.
- `src/state/storage.ts` — localStorage (план хранит только стабильные номера курсов и групп).
- `src/ui/` — компоненты и `styles.css` (токены тем на `:root[data-theme]`).
- `e2e/` — Playwright.

Любое изменение логики индекса или накладок — сначала тест. Контрольный пример в
`misery.test.ts` (реальное расписание: 30 в семестре A, 41 в семестре B) должен оставаться зелёным
или меняться осознанно.
